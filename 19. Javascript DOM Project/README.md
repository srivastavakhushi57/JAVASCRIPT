Features:

- Responsive navigation bar
- Browse multiple laundry and cleaning services
- Service carousel with next and previous buttons
- Add services to the cart
- Skip services
- Remove services from the cart
- Dynamic total amount calculation
- Booking form with:
    i. Full Name
   ii. Email ID
  iii. Phone Number
- Phone number validation
- Booking confirmation popup
- Logout button
- Responsive design for different screen sizes
